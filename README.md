GitHub stores each fork as a separate repository in this account. `ai-tools/sources/` links verified forks through Git submodules pinned to recorded commits. Other tool folders record source and status; a folder alone does not mean the project has been forked.

## Get the verified code

```sh
git clone --recurse-submodules https://github.com/sameeryousaf1111-commits/FORK-KING-1.git
```
